# FSAE 角重量计算器（PWA 在线版）

四轮称重 · 对角重量 · 交叉重量 · 楔形调整 · 重心反算。

## 装到手机主屏

**Android / Chrome**：打开本页 → 右上角 ⋮ → 「安装应用」或「添加到主屏幕」

**iOS / Safari**：打开本页 → 底部「分享」⎙ → 「添加到主屏幕」

装好后从桌面图标一点即开，全屏无地址栏，**离线也能用**。

## 说明

- 单文件应用，无任何外部依赖，所有计算在手机本地完成
- 数据只存在你手机浏览器的 localStorage 里，不上传
- 完整说明见主项目 README
